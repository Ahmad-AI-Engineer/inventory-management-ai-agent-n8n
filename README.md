# Inventory Management AI Agent with n8n

This repository contains an n8n AI agent workflow for inventory management, sales logging, and Google Sheets-based stock tracking.

The workflow uses an AI agent to process inventory-related user messages, update stock levels, and log completed sales into a Google Sheets database.

## Project Overview

This project demonstrates how n8n can be used to build an AI-powered inventory management assistant.

The agent can help with:

- Checking current inventory information
- Processing sales transactions
- Updating inventory quantities
- Logging sold items
- Creating invoice-style sales records
- Using Google Sheets as a lightweight database

| Workflow | Description |
